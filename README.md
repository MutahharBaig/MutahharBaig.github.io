## Design
Restores the original interactive particle network, typing roles, scroll reveals, animated counters, timeline, hover spotlights, 3D card tilt, custom cursor and click effects. Uses graphite and amber by default, with Ember and Silver dark themes available through the theme button. Existing reduced-motion handling is retained.

The photo, social-preview avatar references and CV download button remain removed. All three LinkedIn links use the exact URL supplied. All 14 projects and original experience content are retained.

The contact form composes a draft in the visitor's email app; it does not send email through a server. Career information and metrics come from the supplied portfolio and were not independently verified.

JavaScript syntax, internal anchors, project count, theme wiring and removal of CV/avatar references were checked programmatically. Visual browser testing was not available. The live website has not been changed automatically.
